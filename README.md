## Getting Started

### Install dependencies

```bash
pnpm install
```

### Run the development server

```bash
pnpm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for production

```bash
pnpm run build
```

### Start the production server

```bash
pnpm start
```

### Lint

```bash
pnpm run lint
```
